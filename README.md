
# Planner

## 🇬🇧 English

**Planner** is an offline-first, dark-themed desktop personal planner and productivity app built for Windows. It combines task management, a calendar view, a Pomodoro focus timer, habit tracking, a daily dashboard, and automated local backups into a single interface; storing all your data safely on your own computer without requiring an internet connection or cloud account.

```text
+-----------------------------------------------------------------------+
|  [Planner]     Good Morning 👋                                        |
|  - Today       Today's Tasks | Today's Focus | Today's Habits         |
|  - Inbox       -------------------------------------------------------|
|  - Calendar    Today's Flow (Overdue / Timeline / Unscheduled)        |
|  - Pomodoro    Today's Habits & Weekly Pulse                          |
|  - Habits                                                             |
|  - Settings                                                           |
+-----------------------------------------------------------------------+
📥 Download & Installation
You can download the latest version from the [suspicious link removed] page. Two packages are available:

Setup Wizard (Planner-Setup-0.1.0.exe): Standard Windows installation. Allows choosing the installation directory and creates Desktop/Start Menu shortcuts.

Portable Version (Planner-Portable-0.1.0.exe): No installation required. Just download and run the .exe file from any folder.

Note on Windows SmartScreen:
Since Planner is not signed with a paid commercial Code Signing Certificate, you might see a "Windows protected your PC" warning on the first run.
To run the app: Click "More info", then click "Run anyway".

✨ Features
Daily Dashboard: Dynamic greeting, quick action bar, overdue warnings, timeline, and weekly pulse graph.

Task Management: Inbox, custom lists, priority levels, subtasks, notes, drag-and-drop sorting, and instant search.

Calendar View: Month, Week, Day, and Agenda views with drag-and-drop support.

Pomodoro Timer: Accurate focus, short break, and long break timers with daily/weekly statistics.

Habit Tracking: Boolean or quantitative habits, custom frequencies, streak calculations, and a 12-week heatmap.

Privacy First: 100% offline. Data is stored locally in %APPDATA%\planner\. Includes automatic daily JSON backups.

⚠️ Limitations
No Cloud Sync: Designed to be offline-first. There is no remote server or automatic syncing between devices.

Windows Only: Currently compiled and tested only for 64-bit Windows environments.

(Note: This repository is used for distribution and issue tracking only. The source code is kept private.)



🇹🇷 Türkçe
Planner, Windows için geliştirilmiş çevrimdışı (offline-first), koyu temalı bir masaüstü kişisel planlayıcı ve üretkenlik uygulamasıdır. Görev yönetimi, takvim görünümü, Pomodoro odak zamanlayıcısı, alışkanlık takibi, günlük kontrol paneli ve otomatik yerel yedekleme araçlarını tek bir arayüzde birleştirir; internet bağlantısı veya bulut hesabı gerektirmeden tüm verilerinizi kendi bilgisayarınızda güvenle saklar.

📥 Kurulum (Kullanıcılar İçin)
GitHub deposunun [suspicious link removed] sayfasından en güncel sürümü seçerek iki farklı paketten birini indirebilirsiniz:

Kurulum Sihirbazı (Planner-Setup-0.1.0.exe): Standart Windows kurulumu yapar, kurulum dizinini seçmenize olanak tanır ve Masaüstü / Başlat Menüsü kısayollarını otomatik oluşturur.

Taşınabilir Sürüm (Planner-Portable-0.1.0.exe): Kurulum gerektirmez. İndirdiğiniz tek .exe dosyasını istediğiniz klasörden doğrudan çalıştırabilirsiniz.

Windows SmartScreen Notu:
Planner ticari bir kod imzalama sertifikası ile imzalanmadığından, dosyayı ilk kez çalıştırdığınızda “Windows kişisel bilgisayarınızı korudu” uyarısı görünebilir.
Uygulamayı başlatmak için: Uyarı penceresindeki “Daha fazla bilgi” bağlantısına, ardından açılan bölümdeki “Yine de çalıştır” düğmesine tıklayın.

💾 Veriler ve Yedekleme
Planner tamamen çevrimdışı çalışır ve tüm verileri %APPDATA%\planner\ dizininde saklar.

Otomatik Yedekleme: Her gün otomatik olarak yerel yedek oluşturulur (%APPDATA%\planner\backups\). İstediğiniz zaman uygulama içinden JSON olarak dışa aktarabilir veya geri yükleyebilirsiniz.

✨ Özellikler
Günlük Kontrol Paneli (Bugün): Saate duyarlı dinamik karşılama, 3'lü özet kartları, saat sıralı zaman çizelgesi ve haftalık nabız grafiği.

Kapsamlı Görev Yönetimi: Özel listeler, öncelik seviyeleri, alt görevler, sürükle-bırak sıralama, anlık arama.

Takvim Görünümü: Ay, Hafta, Gün ve Ajanda görünümleri; sürükle-bırak ile görev tarih/saatini değiştirme.

Pomodoro Zamanlayıcı: Sapmasız çalışan odak, mola sayacı; görev bağlama ve günlük/haftalık odak istatistikleri.

Alışkanlık Takibi: Yapıldı/yapılmadı ve sayılabilir hedefler; mevcut/en uzun seri hesaplaması ve etkileşimli ısı haritası.

Bildirimler: Görev ve alışkanlık hatırlatmaları, yerleşik bildirim tonları, sistem tepsisi (Tray) entegrasyonu.

⚠️ Bilinen Sınırlamalar
Bulut senkronizasyonu yoktur: Uzak sunucu, kullanıcı hesabı veya cihazlar arası eşitleme bulunmaz. Tüm veriler sadece sizin bilgisayarınızdadır.

Yalnızca Windows: Uygulama yalnızca 64-bit Windows masaüstü ortamı için paketlenmiştir.
